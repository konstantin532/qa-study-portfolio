# ЗАДАЧА
Создай с нуля учебный SPA-проект «QA Study Portfolio» — трекер подготовки
QA-студента (54 урока, прогресс, повторение карточками, практика, портфолио).

# ЖЁСТКИЕ ОГРАНИЧЕНИЯ
- Чистый HTML + CSS + vanilla JS. БЕЗ фреймворков, БЕЗ сборки, БЕЗ CDN.
- Сайт обязан работать при открытии по file:// (двойной клик по index.html).
- Одна тёмная тема (без переключателя light/dark).
- Все цвета и отступы — ТОЛЬКО через CSS-переменные. В правилах не хардкодить
  цвета (кроме @media print).

# СТРУКТУРА ПРОЕКТА
index.html
css/
  01-base-reset-vars.css        — reset + ВСЕ CSS-переменные (дизайн-токены)

# ПРАВИЛА КАСКАДА (критично!)
- Каждый класс описан ровно один раз, в своём файле по назначению.
- Не дублировать правила между файлами; 09 ничего не «чинит», только печать.
- Каждый страничный контейнер обязан иметь явное правило:
  display: flex; flex-direction: column; gap: 20px;
  (.dashboard, .today, .repetition, .practice-board, .practice-task,
   .mindmap-canvas, .mindmap-children, .notes, .stats, .settings-form,
   .questions-list, .question-options, .question-hint)
  Запрещены «неописанные» div-обёртки карточек — источник слипания блоков.
- Сетки: .grid-2/.grid-3/.grid-4 — mobile-first (1fr), от 768/1280px — 2/3/4
  колонки; gap: 20px. .grid-auto — repeat(auto-fit, minmax(280px, 1fr)).
- .card — в 05: background var(--surface-raised); border var(--border);
  border-radius var(--radius-md); padding var(--space-4); декоративный
  золотой уголок через ::before (border-top + border-right, 2px,
  var(--gold-line), размер var(--deco-corner-size), top/right var(--space-1));
  hover: translateY(-2px) + var(--shadow-md).
- Специфичность: без #id в правилах компонентов; без !important вне @media print.

# JS-ПОВЕДЕНИЕ
1) Tilt-эффект карточек: perspective 600px на контейнере, rotateX/rotateY
   по позиции мыши (±6deg), CSS-переменные --glare-x/--glare-y; transition
   transform 200ms cubic-bezier(.4,0,.2,1); transform-style preserve-3d.
2) Появление карточек: opacity+translateY, transition 300ms, каскадные
   задержки 50/150/200ms.
3) .progress-fill: scaleX(0)→scaleX(p) с --fill-ready, origin left.
4) Данные в localStorage: прогресс уроков (0/54), серия (дни), минуты,
   портфолио, настройки. Сброс в настройках.
5) Тосты (контейнер #toast-container, авто-скрытие, типы info/success/
   warning/danger). Модалки #modals. Индикатор сохранения #save-indicator.

# ДОСТУПНОСТЬ И РЕЖИМЫ
skip-link → #main-content (tab); aria-current в хлебных крошках; role=
"progressbar" c aria-valuemin/max/now; toggle с role/aria-checked;
focus-visible золотым outline; @media (prefers-reduced-motion: reduce) —
все анимации ≤1ms; @media (forced-colors: active) — Highlight/Canvas/
ButtonText; @media print (09): скрыть sidebar/header/panel, ч/б палитра,
URL после внешних ссылок, break-inside: avoid на карточках, @page margin 15mm.
