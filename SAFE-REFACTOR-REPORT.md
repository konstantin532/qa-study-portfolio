# SAFE-REFACTOR-REPORT.md

## Что сделано

Проект исправлен консервативно: визуальный дизайн, маршрутизация, формат пользовательских данных и публичные имена основных модулей не менялись. Цель правки — закрыть подтверждённые риски без большого переписывания и без тяжёлых новых runtime-зависимостей.

- Удалён устаревший вложенный qa-study-portfolio.zip (−6,45 МБ из исходного дерева).
- Добавлен ранний safe-storage.js: защита от битого JSON, запрета Storage и QuotaExceededError с fallback в памяти.
- Добавлен security.js: DOM-sanitizer и безопасное глубокое копирование импортируемого JSON без prototype-pollution ключей.
- debug.js переведён в режим opt-in (?debug=1), поэтому обычная страница загружает примерно на 38 КБ меньше JavaScript.
- 11 прямых вызовов localStorage/sessionStorage направлены через безопасный facade.
- Fallback-импорт теперь очищает структуру JSON перед сохранением.
- 2 динамических HTML-вставок main.js переведены на sanitizer без изменения визуальной разметки.
- Добавлены npm-проверки синтаксиса, целостности, порядка загрузки, XSS-escaping и prototype-pollution защиты.
- Две `_importDataManual` проверены через AST: они находятся в разных функциональных областях, поэтому безопасно сохранены; ошибочного взаимного затенения нет.


## Производительность

`debug.js` теперь загружается только с параметром `?debug=1`. В обычном режиме браузер не загружает и не разбирает этот отладочный модуль. Вложенный архив удалён из дерева проекта. Новые защитные модули компактны, не используют внешние библиотеки и выполняют тяжёлую DOM-очистку только в исправленных динамических точках, а не на всей странице.

## Проверка перед публикацией

```bash
npm install
npm run check
```

Для обычного запуска:

```bash
npm run serve
```

Откройте `http://localhost:4173/index.html`. Для отладочного режима используйте `http://localhost:4173/index.html?debug=1`.

## Рекомендуемый smoke-test

Проверьте открытие всех разделов, создание и редактирование артефакта, экспорт JSON, импорт экспортированного JSON в режимах merge и replace, поиск с символами `<`, `>`, `&`, кавычками, десятикратное открытие/закрытие модального окна, перезагрузку страницы и мобильную ширину 375 px.

## Важно

Крупные файлы намеренно не были массово разбиты или минифицированы в этой версии: такой рефакторинг без полного набора визуальных и бизнес-тестов создаёт больший риск регрессии, чем пользу. Архив сохраняет читаемый исходный код и совместимость с текущим статическим запуском.
