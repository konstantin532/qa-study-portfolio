# Этап 1 — стабилизация

Подготовлена воспроизводимая система браузерных проверок для ключевых рисков: ошибки консоли, критические нарушения доступности, клавиатурный фокус, доступные имена полей, уникальность DOM ID, отправка форм и отказоустойчивость localStorage.

## Добавлено

- `playwright.config.cjs` — Chromium-проверки desktop и mobile.
- `tests/stabilization.spec.cjs` — 8 стабилизационных сценариев.
- `tests/static-checks.cjs` — проверка локальных ресурсов и повторяющихся ID.
- `.github/workflows/stabilization.yml` — автоматический запуск на push и pull request.
- `package.json` — единые команды установки, запуска и отчёта.

## Первичный статический аудит

- Форм в исходной HTML-разметке: 0.
- Диалогов/модальных контейнеров: 6.
- Подключённых локальных JS-файлов: 10.
- Подключённых CSS-файлов: 9.
- Повторяющиеся ID: не найдены.
- Отсутствующие подключённые ресурсы: не найдены.
- Поля без статически определимого доступного имени: 1.
- Статически обнаруженные ключи localStorage: литеральные ключи не найдены (возможны динамические ключи).

## Запуск

```bash
npm install
npx playwright install chromium
npm run check:static
npm test
```

HTML-отчёт после тестов открывается командой `npm run test:report`. Тест намеренно считается неуспешным при ошибках консоли, серьёзных/критических нарушениях axe, необработанном повреждении JSON или ошибке квоты хранилища — это превращает скрытые дефекты в конкретные воспроизводимые задачи.

## Ограничение локальной среды

В текущей среде не установлен Node.js, поэтому полный Playwright/axe-прогон здесь не выполнялся. Конфигурация CI запускает его в GitHub Actions на Node.js 20; локально он запускается командами выше. Статический аудит исходной разметки выполнен при подготовке пакета.
