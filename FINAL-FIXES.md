# Финальные исправления интерфейса

## Что такое «Контекст»

`#context-panel` — общий контейнер проекта для предпросмотра и редактирования выбранного артефакта. Ранее он раскладывался как нижняя строка оболочки приложения, поэтому выглядел как мешающий нижний бар, а редактор появлялся слева снизу.

Теперь закрытая панель полностью скрыта. При открытии она становится модальным окном по центру экрана с затемнением фона, внутренней прокруткой, закрытием по кнопке, Escape и клику по фону. На мобильном экране редактор занимает весь экран.

## Файлы

- `css/final-interface-fixes.css` — центрирование диалога, изолированная прокрутка, адаптивность и исправление элементов дорожной карты.
- `js/final-interface-fixes.js` — доступность диалога, фокус, Escape, клик по фону; чистый JavaScript.
- `index.html` — подключение исправлений и внутренняя поверхность диалога.
- `START-WINDOWS.bat` — запуск из правильной папки через локальный сервер.

Не открывайте `index.html` через `file:///`: браузер ограничивает часть функций, из-за чего возможны уведомления «Произошла ошибка». Используйте `START-WINDOWS.bat` или `npm run serve` и адрес `http://127.0.0.1:4173/index.html`.
