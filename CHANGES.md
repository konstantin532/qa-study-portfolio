# Отчёт об изменениях

## Исправлено

- Удалена нерабочая ссылка на отсутствующий `js/ui-hotfix.js`, вызывавшая HTTP 404.
- Восстановлен отсутствовавший ресурс `css/ui-recovery-hotfix.css`: файл находился в каталоге `js`, тогда как HTML загружал его из `css`.
- Удалён вложенный архив проекта, который дублировал исходники и увеличивал репозиторий.
- Добавлен изолированный финальный слой `css/polish.css` без изменения бизнес-логики приложения.
- Усилена защита от горизонтального переполнения и длинных значений; улучшено поведение таблиц и диалогов на узких и низких экранах.
- Унифицированы состояния фокуса, наведения, нажатия и недоступности интерактивных элементов.
- Добавлены адаптивные ограничения модальных окон и минимальные размеры элементов управления на мобильных устройствах.
- Добавлены поддержка `prefers-reduced-motion` и усиленный фокус для `prefers-contrast`.
- Добавлены ненавязчивые динамические улучшения: индикатор прокрутки и однократное появление карточек через `IntersectionObserver`.
- Динамика реализована прогрессивно: без JavaScript и при отключённых анимациях содержимое остаётся доступным.
- Дополнен README с инструкцией локального запуска и описанием порядка CSS-слоёв.

## Архитектурная заметка

В проекте остаются крупные исторические CSS- и JavaScript-файлы. Полная декомпозиция требует отдельного регрессионного цикла по всем экранам и сценариям. В этой версии применены безопасные изменения с минимальным риском нарушения существующей функциональности.
